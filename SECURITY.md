# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 2.x | Yes |
| 1.x | No. Upgrade to 2.x, which requires `mcp-server` 0.5.x |

## Reporting a Vulnerability

Security information can be found in our [security.txt file](https://academy.jahia.com/.well-known/security.txt).

Security-relevant design decisions, and the risks accepted for them, are listed in the
[README security notes](README.md#security-notes) and in [CLAUDE.md](CLAUDE.md#accepted-risks).
